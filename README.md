# 🌲Nightly Tree 抗藍光遮罩工具
## ⌨️專案簡介

Nightly Tree 是一個開源的抗藍光遮罩工具，專為舊版 Windows 系統設計。

此專案使用 .NET Framework 2.0 開發，確保其在古老系統上的最大相容性。

## ✨主要特色功能
系統相容性： 適用於 Windows 2000 SP3 及以上系統，包括 Windows XP / Vista / 7。

漸進式淡入： 啟動或啟用時，遮罩會緩慢淡入，提供更舒適的視覺體驗。

系統匣控制： 程式在系統匣中運行，點擊圖示即可呼出設定介面。

輕量且開源： 程式碼簡潔，資源佔用極低，且完全開源（MIT 授權）。

## 💾系統需求
作業系統: Windows 2000 Service Pack 3 及以上（包括 XP, Vista, 7, 8, 10, 11）。

執行環境: 必須安裝 .NET Framework 2.0 或以上版本。

[.NET Framework 2.0 官方下載點 (x86)](https://www.microsoft.com/zh-tw/download/details.aspx?id=16614&msockid=123f4a285cf9606a062b5cb75dd26186)

## 🧭如何使用
[下載](https://github.com/StupidestJack/NightlyTree/releases/)並執行 Release 版本即可。

點擊圖示，即可開啟設定視窗，調整你想要的色調和強度。

 > [!WARNING]
 > 雖然程式可以在多螢幕環境下運行，但目前僅對主螢幕提供遮罩。多螢幕的支援正在規劃中。

## 🐞已知問題
 - 此軟體無法使用UIAccess權限，因此螢幕小鍵盤、工作管理員等程式可能會蓋住此軟體的遮罩，且無法覆蓋新版本開始選單。
 > 💸我還是個孩子啊，哪來那麼多錢買證書QAQ
 - 此軟體會被截圖擷取，可能導致螢幕擷取圖片泛黃。
 - 此軟體不建議在多重螢幕下使用，此版本尚未對多螢幕延伸模式進行相容。
 > 此問題待修復
